## Privacy policy / Confidentialité

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

When the user enables these features, the app contacts the following services directly, only to download public data: SimBrief (the user's own flight plan, with the SimBrief ID the user typed), FSHub (public flight radar; optional FSHub key typed by the user), OpenStreetMap / Overpass (airport layouts), NOAA (METAR), Esri and OpenStreetMap (map tiles), OurAirports (airport list). No personal data is collected by the author. Settings stay on the user's PC (`%APPDATA%\HangarFS2024`).

*Ce programme n'envoie aucune information à d'autres systèmes en réseau, sauf à la demande de l'utilisateur. Les réglages restent sur le PC de l'utilisateur.*
